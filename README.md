# doofenschmirtz

> Do good. Earn points. Get rewards.

doofenschmirtz is an experimental reward platform created for TLE1 at CMGT, Hogeschool Rotterdam. It is an educational, non-commercial project exploring whether positive contributions can be rewarded with points and benefits.

## Current foundation

- Plain HTML and JavaScript frontend
- PHP front controller backend
- Local MySQL/MariaDB database
- Session-based authentication

Current authentication endpoints:

```text
POST /auth/register
POST /auth/login
```
