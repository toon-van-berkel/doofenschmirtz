# doofenschmirtz

> Do good. Earn points. Get rewards.

**doofenschmirtz** is an experimental reward platform created for TLE1 at CMGT, Hogeschool Rotterdam.

The project explores a simple idea:

**What if positive contributions to society and the environment were rewarded with experiences and other benefits?**

Instead of taking rights or privileges away from people, everyone keeps the same basic rights. The system only adds optional rewards for positive actions.

---

## 💡 The concept

The system works in three simple steps:

1. **Complete a positive task**  
   A user performs an activity that benefits society, a community or the environment.

2. **Earn points**  
   Completing and verifying the activity rewards the user with points.

3. **Spend points on rewards**  
   Points can be exchanged for additional rewards and experiences.

Examples of rewards could include:

- 🎵 Concert tickets
- 🎟️ Event tickets
- 🎬 Cinema tickets
- 🌳 Recreational activities
- 🎁 Special rewards
- 💸 Discounts
- 🏛️ Local community benefits

---

## 🌍 Example tasks

Tasks could include activities such as:

- Cleaning litter from a public area
- Helping at a community event
- Volunteering
- Participating in environmental projects
- Helping another person
- Recycling or returning reusable materials
- Contributing to local initiatives

The exact tasks and rewards are part of the experiment and may change during development.

---

## 🔄 Basic flow

```text
Positive action
      ↓
Task completed
      ↓
Verification
      ↓
Points awarded
      ↓
Point balance
      ↓
Reward marketplace
      ↓
Reward claimed
```

---

## 🎯 Project goal

The goal of this project is to investigate whether a reward system can motivate people to contribute more frequently to their surroundings, community and environment.

The project is not intended to determine someone's worth or remove access to basic rights.

Rewards are designed as **additional benefits** on top of the rights and services everybody already has.

---

## 🧪 Experimental project

This repository is part of **TLE1 – Experimenteren** at CMGT, Hogeschool Rotterdam.

The concept will be developed through prototypes, experimentation and user testing.

Because this is an experimental project, functionality, rules and reward mechanisms may change significantly between iterations.

---

## 🛠️ Tech Stack

The project uses a lightweight web stack:

- **PHP** — server-side logic
- **HTML** — page structure
- **CSS** — styling and layout
- **JavaScript** — client-side interaction

The project intentionally avoids larger frontend frameworks to keep the prototype lightweight and easy to develop and deploy.
